# 快速开始

> 目标：5 分钟内，让团子出现在屏幕右下角、随 ZCode 干活而动。全程不需要管理员权限。

## 第 1 步 · 安装 Z-Buddy 应用

从[下载页](/Z-Buddy/download/)获取安装包（`Z-Buddy_x.y.z_x64-setup.exe`），双击运行：

- 若 Windows 弹出 SmartScreen 提示，点 **更多信息 → 仍要运行**（个人项目暂未购买代码签名证书，详见[下载页说明](/Z-Buddy/download/)）；
- 向导中自选安装路径，可选勾选「开机自启」。

**你应该看到**：桌面右下角出现一只静止的白色团子。它现在不动，因为还没有插件告诉它 ZCode 在干什么——下一步就是装插件。

## 第 2 步 · 安装 z-buddy 插件

宠物动起来的信息来自 ZCode 插件（hooks 生命周期上报）。两种装法：

**方式 A · 直接添加市场（推荐）**：在 ZCode 中打开 设置 → 插件市场 → 添加市场，输入：

```
learnerCodeZ/Z-Buddy
```

**方式 B · 本地市场**：克隆仓库后，把其中的 `marketplace/` 文件夹作为本地市场添加：

```bash
git clone https://github.com/learnerCodeZ/Z-Buddy.git
```

然后在市场列表中安装 **z-buddy** 插件。

:::note
插件的 hook 配置在**会话启动时快照**——装完插件后必须**新建一个 ZCode 会话**才会生效。这是最常见的一步坑。
:::

**你应该看到**：插件列表里 z-buddy 显示已安装。

## 第 3 步 · 看它动起来

在新建的 ZCode 会话里随便干点活（比如让它读一个文件）：

| ZCode 正在 | 团子会 |
|---|---|
| 思考你的输入 | 🤔 歪头 |
| 执行工具（读文件/跑命令） | ⌨️ 敲键盘 |
| 请求权限 | ❓ 求关注 |
| 执行失败 | 😵 X 眼冒汗 |
| 深夜（23 点后）空闲 | 💤 睡着冒 Zzz |

**你应该看到**：团子随上述状态切换动画。到这一步，安装闭环完成 🎉

## 装完必玩

- **点一下团子** → 暂停：ZCode 的下一步工具调用会被拦截（宠物置灰 + ⏸ 角标）；再点一下恢复。想跑某个豁免命令，在命令里带上 `.z-buddy/pause` 路径即可绕过。
- **按住团子拖动** → 换个顺眼的角落挂机（它自己会回到不挡事的位置）。
- **右键托盘图标** → 显示/隐藏、切换宠物、退出。
- **换宠物**：把宠物包放进 `~/.z-buddy/pets/<名字>/`（内含 `atlas.png` + `pet.json`），重启应用或从托盘切换。
