# 声明

## 独立开源项目

Z-Buddy 是由个人开发者 learnerCodeZ 独立开发的开源项目，与 Z.ai（智谱AI）无任何隶属、赞助或官方合作关系。

## 商标说明

- **Codex** 是 OpenAI 的注册商标，本文档及网站中提及仅作技术对照，不构成任何形式的关联或背书。
- **ZCode** 是智谱 AI 的产品名称，Z-Buddy 为其提供独立的插件和配套工具，不代表官方立场。

## 宠物形象

Z-Buddy 内置的宠物形象（团子 Mochi、抹茶 Matcha）均为本项目原创美术作品，由程序化生成脚本产出，版权完全归属项目所有。

宠物包格式兼容 Codex hatch-pet 的精灵图思路，但并非官方格式；社区宠物包如需投稿，需确保原创性或已获授权，项目拒绝接受任何可能侵犯第三方知识产权的内容。

## 灵感来源

Z-Buddy 的设计灵感来源于：

- [Codex Pet Mode](https://openai.com) — OpenAI Codex 的宠物模式
- [clawd-on-desk](https://github.com/rullerzhou-afk/clawd-on-desk) — 通用 Agent 桌宠项目

感谢这些项目对 AI 编程助手可视化交互方向的探索。

## 隐私

- Z-Buddy 插件仅将 Agent 状态数据写入本机 `~/.z-buddy/` 目录，不上传任何数据。
- 聊天功能（规划中）将直连用户自行配置的 GLM API Key，聊天记录仅存内存、不落盘。
- 本项目收集的唯一数据是 GitHub Star 数和 Issue 数量，均为公开数据。
