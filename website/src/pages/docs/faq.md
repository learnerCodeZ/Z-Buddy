# FAQ / 故障排查

先列高频问题，再列「现象 → 排查」对照表。以下坑全部来自真实开发/实测过程。

## 高频问题

### 和 Codex 的宠物模式是什么关系？

灵感与敬意来源。Z-Buddy 是为 ZCode 而生的独立开源实现，宠物包格式兼容其开放的精灵图思路（横向分帧、行=状态）——完整的格式约定见[宠物包规范 v1](/Z-Buddy/docs/pet-pack-spec/)。

### 收费吗？

免费开源，代码采用 MIT（已定稿，见仓库 LICENSE）。唯一的可选成本是未来聊天功能调用 GLM API——用你自己的 Key，费用与本项目无关。

### 它会读我的代码、上传数据吗？

不上传。插件只把 Agent 状态写入本机 `~/.z-buddy/state.json` 和 `~/.z-buddy/events.jsonl`，桌宠读取后播放动画，数据全程不出你的电脑。

### 支持 macOS / Linux 吗？

Windows 优先（10/11 x64）。应用基于 Tauri，跨平台可行，排在 Windows 稳定之后。

## 现象排查

### 桌宠根本没出现

1. 检查应用是否在运行（托盘溢出区找图标，时钟旁 `^` 展开）；
2. 若刚装完：从开始菜单手动启动一次 Z-Buddy；
3. 桌宠首次启动会出现在主屏右下角，先找主屏（拖动过的位置会被记住）。

### 桌宠在，但永远不动（也不睡）

八成是插件没生效。按顺序检查：

1. 插件市场里 z-buddy 是否显示**已安装**；
2. **是否新建了 ZCode 会话**——hook 配置在会话启动时快照，装完不新建会话等于没装（最高频原因）；
3. 有「等待审批」以外的静止状态吗？让 ZCode 跑个简单命令（如读文件）试试。

### 点了桌宠，ZCode 没停

1. 看桌宠是否已置灰并显示 ⏸ 角标——没有则暂停未生效；
2. 暂停通过拦截**下一次工具调用**实现，如果 ZCode 正在长时间执行一个工具，要等这次调用结束后才停；
3. 想放行特定命令：命令文本中包含 `.z-buddy/pause` 路径的调用会被豁免。

### 桌宠拖不动

**长按**桌宠身体约 0.15 秒（它会换成被拎起的形象）再拖动。位移超过 6px 才会判定为拖拽——这是为了区分「点一下暂停」和「拖走」两种手势。

### 杀毒软件 / SmartScreen 拦截

个人项目暂未购买代码签名证书，属于已知情况：

- SmartScreen：**更多信息 → 仍要运行**；
- 第三方杀软误报：把安装目录加入白名单，或先用 Release 里的 SHA256SUMS 核对文件完整性。

### 多个 ZCode 会话时状态串台

v0.1.x 的状态是「最后写入者胜」——多个会话同时干活时，桌宠只反映最近说话的那个。**多会话聚合已完成开发**（每会话独立状态分片、按"出错 > 等审批 > 干活"优先级显示），将随下个版本发布。

## 还是不行？

到 [GitHub Issues](https://github.com/learnerCodeZ/Z-Buddy/issues) 提一个问题，附上：ZCode 版本、Windows 版本、`~/.z-buddy/` 下 `state.json` 与 `events.jsonl` 的内容（都是状态数据，不含代码内容）。
