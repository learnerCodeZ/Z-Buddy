## 会话管理

ZCode 的每一次对话都叫一个「会话（Session）」，会话结束后数据不会消失，可以随时回溯。

### 会话数据存在哪？

ZCode 的会话**不是**独立的 JSON 文件，而是存在 SQLite 数据库里：

- 数据库位置：`~/.zcode/v2/tasks-index.sqlite`
- 每个会话在数据库 `tasks` 表中是一条记录，包含：`task_id`（会话 ID）、`title`（标题）、`task_status`（状态）、`workspace_path`（所属项目）等字段
- 右键菜单「复制任务路径」复制的是类似 `D:\MYCODE\Z-Buddy/sess_xxx.zcode-session` 的路径，但实际数据在 SQLite 里

### 会话 ID 是什么？

- 格式：`sess_752b8f30-1805-4ce1-b742-6aa295aa02fc`（UUID）
- 本质：数据库中的主键，唯一标识一次对话
- 用途：提 bug 时附上（帮助开发者定位问题）、查询会话历史
- 怎么拿：右键会话 → 复制会话 ID

### 与 DeepSeek Harness 的区别

| 工具 | 会话存储方式 | 导出方式 |
|---|---|---|
| DeepSeek Harness | 独立 JSON 文件（每个 session 一个文件） | 直接复制 JSON 文件即可分享 |
| ZCode | SQLite 数据库（所有 session 存在一个 `.sqlite` 文件里） | 需要通过 UI 操作或查询数据库 |

### ZCode 用户如何导出会话？

- **方法 1（推荐）**：右键会话 → 复制会话 ID → 用 DB 浏览工具打开 `~/.zcode/v2/tasks-index.sqlite`，查询 `tasks` 表中 `task_id = 'sess_xxx'` 的记录
- **方法 2**：复制日志路径，日志文件（JSONL 格式）包含更详细的运行时数据
- **方法 3**：如果会话仍在 ZCode 中可见，直接在 UI 中查看历史消息即可

## 调用轨迹

「调用轨迹」是 Agent 每一步操作的完整记录——读了哪些文件、跑了什么命令、调用了什么工具、花了多久。

### 怎么查看？

1. 右键会话 → 复制日志路径
2. 日志文件位置：`~/.zcode/cli/log/zcode-YYYY-MM-DD.jsonl`（按日期分文件）
3. 格式：JSONL（每行一条 JSON），包含时间戳、事件类型、模块名、traceId 等结构化数据
4. 用 VS Code / 记事本打开即可查看；搜索关键词（如 `PreToolUse`、`PostToolUse`、`error`）可快速定位

### 日志里有什么？

- 每次模型请求的开始/完成时间
- 工具调用记录（读文件、跑命令等）
- 网络请求状态
- 错误与异常信息
- `traceId`（调用链追踪 ID，一次完整任务的所有步骤共享同一个 traceId）

### 三者区别

| 文件 | 位置 | 内容 | 用途 |
|---|---|---|---|
| 会话数据 | `~/.zcode/v2/tasks-index.sqlite` | 消息历史（你和 AI 的对话） | 回溯对话、分享给别人 |
| 运行日志 | `~/.zcode/cli/log/zcode-YYYY-MM-DD.jsonl` | 系统级事件（请求、响应、错误） | 排查系统问题、看请求耗时 |
| 调用轨迹 | 从日志中提取 | Agent 的工具调用链 | 复盘"AI 到底干了什么" |

### 什么时候有用？

- 排查"AI 到底干了什么"（尤其是执行了删除、修改等破坏性操作后）
- 复盘失败任务（看哪一步出了问题）
- 写复盘笔记（日志就是最准确的素材）

## 右键菜单五大功能

右键点击侧边栏的会话条目，会出现以下菜单：

| 功能 | 复制的内容 | 典型场景 |
|---|---|---|
| **复制路径** | 项目本地路径（如 `D:\MYCODE\Z-Buddy`） | 让别人打开你的项目、脚本引用项目根目录 |
| **复制任务路径** | 任务（Goal）的存储路径 | 查看任务历史、手动编辑任务配置 |
| **复制日志路径** | 运行日志文件路径（`~/.zcode/cli/log/zcode-YYYY-MM-DD.jsonl`） | 用编辑器查看完整运行日志与调用轨迹 |
| **复制会话 ID** | 会话 UUID（如 `sess_752b8f30-...`） | 提 bug 时附上、跨设备恢复会话 |
| **前往配置** | 跳转到 ZCode 设置页 | 快速改模型/插件/快捷键，不用从菜单层层进入 |

## 常见疑问

### 会话路径里的 UUID 是什么？

会话路径格式为 `<项目目录>/sess_<UUID>.zcode-session`，其中 `sess_` 前缀 + 32 位 UUID 是 ZCode 自动生成的唯一标识。每次新建会话都会分配一个新的 UUID，确保不同对话不会互相覆盖。UUID 本身没有特殊含义，只是一个随机生成的唯一编号。

### 会话文件和日志文件是同一个东西吗？

不是。会话数据在 SQLite 数据库里（包含消息历史），日志文件在 `~/.zcode/cli/log/` 下（包含工具调用的详细记录）。右键菜单里的「复制任务路径」和「复制日志路径」指向不同的位置。

### 这个页面和 FAQ 有什么区别？

FAQ 解决的是"遇到问题怎么办"（故障排查），实用技巧解决的是"怎么用得更好"（效率提升）。FAQ 是被动的，实用技巧是主动的。
