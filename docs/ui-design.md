# Z-Buddy 主界面设计方案

> 版本：v1 设计稿（2026-09-06）
> 状态：待评审 → 评审通过后实施
> 关联：立项报告 §8.6.2（后台任务气泡）、想法池 #6（桌面驾驶舱）、Phase 2 路线图

---

## 1. 为什么要主界面

现在 Z-Buddy 的全部交互只有 160×300 的一只宠物 + 托盘三菜单。状态一览靠悬停小卡，够轻但**装不下更多信息**：事件历史、宠物管理、设置、将来的任务面板和养成系统都需要一个"家"。

主界面的定位一句话：**宠物的驾驶舱**——轻交互留在宠物身上（点击/拖动/悬停），重信息收进主界面。

## 2. 入口设计（三条路都能到）

1. **托盘右键菜单**（用户指定诉求）：在现有菜单基础上增加两项，排序如下——

```
打开主界面            ← 新增，最常用放最上
──────────────
显示 / 隐藏宠物
切换宠物
──────────────
打开官方网站          ← 新增
──────────────
退出 Z-Buddy
```

2. **宠物本体右键**：右键团子弹出与托盘同款的上下文菜单（Tauri `Menu.popup()`），里面同样有"打开主界面"。左键保留"暂停/恢复"不变；
3. **悬停卡**：卡片底部提示行预留一个"打开面板"入口（Phase 2，卡片当前纯展示）。

**官方网站入口**：菜单项"打开官方网站"用 `tauri-plugin-opener` 打开浏览器。官网未上线前指向 **GitHub 仓库页**（README 即官网内容），域名定下来后一行配置切换。官网站点本身列入 Phase 2（静态页：介绍 / 下载 / 宠物画廊 / 文档，可直接用 GitHub Pages 零成本托管）。

## 3. 窗口规格

| 项 | 规格 |
|---|---|
| 尺寸 | 920 × 620 逻辑像素，可缩放（最小 760×520），位置记忆（关哪开哪） |
| 风格 | 无边框自绘标题栏，深色底 `#1e2229`，延续像素风（圆角卡片 + 团子元素点缀） |
| 单实例 | 已有主界面时再次触发 → 聚焦既有窗口而不是开第二个（tauri single-instance） |
| 关闭行为 | 点 ✕ = 隐藏到托盘（宠物还在），真正退出只走托盘"退出" |
| 多窗口关系 | 宠物窗（置顶小窗）与主窗（普通窗）独立存在，共享同一份 Rust 状态与配置 |

## 4. 信息架构（五个页签，两期交付）

### 4.1 总览（Dashboard，默认页）

一屏回答三个问题：**它在干嘛？我能不能管它？刚才发生了什么？**

```
┌────────────────────────────────────────────────────────────┐
│  ┌──────────────┐   状态：干活中 ⌨️            [⏸ 暂停]   │
│  │              │   当前工具：Bash                          │
│  │  团子 256px   │   会话：sess_live · 已运行 4 分 12 秒     │
│  │  (动画同步)   │   ────────────────────────────────       │
│  │              │   今日统计：任务 3 · 工具调用 47 · 暂停 1 次│
│  └──────────────┘                                          │
│  ┌────────────────────────────────────────────┐            │
│  │ 最近事件（实时）                             │            │
│  │  13:42  PreToolUse       Bash              │            │
│  │  13:42  PostToolUse      Bash              │            │
│  │  13:41  PreToolUse       Write             │            │
│  └────────────────────────────────────────────┘            │
└────────────────────────────────────────────────────────────┘
```

- 左侧大图：**与角落宠物同帧同步**（读同一 state + 同一动画时钟，桌面上的团子跳一下，这里也跳一下——细节即生命感）；
- 暂停大按钮：与宠物单击等效（同一个 pause 文件），状态互相同步；
- 事件时间线：读 `events.jsonl` 尾部（增量），色点区分事件类型。

### 4.2 宠物（Pet 管理页）

- 宠物网格卡：扫描**内置包**（mochi）+ **外部包**（`~/.z-buddy/pets/*/`），每卡显示大图（idle 首帧）+ 名字 + 来源标签（内置/外部）+ "使用中"高亮；
- 点击卡片 = 切换宠物（写 app.json + 广播 `pet-changed`，角落宠物当场变身）；
- 空态引导："把宠物包文件夹放进 `~/.z-buddy/pets/`，刷新即见" + 指向格式文档；
- P2 预留入口：**hatch 生成**（GLM 一句话造宠物）与**宠物画廊**（下载别人的包）。

### 4.3 活动（Activity）

- `events.jsonl` 全量时间线：按会话分组、按事件类型筛选（PreToolUse / PostToolUseFailure / Stop…）、关键字搜索；
- 每条可展开看 preview（命令/文件摘要）；
- 这就是立项书 8.6.2"后台任务气泡"的完整版——气泡管"此刻"，本页管"历史"。

### 4.4 任务（Tasks，P2 灰置）

- 读 ZCode 的 `tasks-index.sqlite`：错峰任务、自动化任务、任务历史（Phase 0 已验证可直读）；
- 对齐立项书 8.6.2 的任务行设计 + "取消 = 深链回 ZCode"降级方案。

### 4.5 设置（Settings）

| 设置项 | 控件 | 落盘 |
|---|---|---|
| 开机自启 | 开关 | tauri-plugin-autostart（注册/注销自启项） |
| 当前宠物 | 下拉 | app.json `pet` |
| 暂停状态 | 开关 | pause 文件 |
| 关闭主界面行为 | 最小化到托盘 / 退出应用 | app.json `closeBehavior` |
| 语言 | 中文 / English（i18n 骨架） | app.json `locale` |
| 关于 | 版本号、检查更新、GitHub、官方网站 | — |

## 5. 技术实现要点

1. **多窗口**：`WebviewWindowBuilder::new(app, "main", WebviewWindowBuilder::config…)` 新建主窗；宠物窗逻辑零改动；
2. **状态共享**：主窗与宠物窗调同一批 Rust command（read_state / set_pause / list_external_pets），无新数据通道；
3. **事件面板**：Rust 增 `read_events(offset)` 命令（读 events.jsonl 尾部 N 行），前端 1s 轮询或 fs watch；
4. **单实例**：`tauri-plugin-single-instance`——二次启动聚焦主窗；
5. **自启**：`tauri-plugin-autostart`（替代现在的启动文件夹快捷方式，设置页开关可控）；
6. **打开网站**：复用已有 `tauri-plugin-opener`；
7. **托盘菜单**：`MenuItem` 加两项 + `on_menu_event` 分支，`Menu.popup()` 供宠物右键复用同一菜单。

## 7. 官方网站最小规划（Phase 2，GitHub Pages 零成本）

- 域名占位：`z-buddy.<你的域>` 或先 `learnercodez.github.io/Z-Buddy`；
- 页面：首页（一句话 + 下载按钮指 Release）· 宠物画廊（pet.json 索引）· 文档（安装/宠物包格式/hook 说明）；
- 菜单"打开官方网站"的 URL 常量化在 Rust 侧，上线即切换。
